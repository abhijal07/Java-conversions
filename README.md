# Java Conversions

This repository contains beginner-level Java programs that demonstrate
number system conversions and basic mathematical calculations without
using arrays.

## Topics Covered

- Decimal to Binary conversion
- Binary to Decimal conversion (using Math.pow)
- Decimal to Octal conversion
- Octal to Decimal conversion
- HCF (Highest Common Factor) calculation
- LCM calculation using HCF

## Concepts Used

- Loops (for / while)
- Conditional statements
- Arithmetic operations
- Math.pow() function
- Number system logic

Language: Java  
Level: Beginner
